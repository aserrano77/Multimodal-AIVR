# Exclusiones y limitaciones

- Privacidad: se omiten datos individuales, pseudónimos, respuestas, comentarios y telemetría.
- Seguridad: se omiten credenciales, configuración de cuentas y metadatos locales.
- Licencias: se omiten assets, modelos, audios y tipografías cuya redistribución no está confirmada.
- Tamaño: no se incluyen APK, builds, cachés ni registros.
- Contenido generado: se omiten salidas intermedias, cachés y resultados técnicos.
- Dependencias restaurables: se conservan manifiestos, pero no SDK, runtimes ni paquetes completos de terceros.
- Historia: se omiten documentación candidata, copias de respaldo y evidencias de desarrollo.
- El README original del pipeline conserva una referencia histórica al diseño 2x2 y no se ha modificado.
- El resolver de datos conserva una ruta de desarrollo local utilizada para construir instrucciones y sugerencias de exportación de escritorio. Esas operaciones pueden requerir configurar o adaptar el destino en otro equipo.
- El directorio ExportedQuestData y todos sus datos están excluidos y no se distribuyen.
